# 功能清单

本文描述当前代码已实现的能力。线上实例的版本和开关单独记录在[当前实例](deployment/current-instance.md)，后续工作见 [Roadmap](roadmap.md)。

## 项目用途

Glean 将历史文献、持续发现、机器处理和人工审核放在同一工作台中。研究者可以按主题检索论文、查看原始来源和出版证据、维护阅读进度；管理员负责共享目录、检索方案和纳入决定。

界面以中文阅读为主，保留来源原文与英文题名，支持桌面和手机。

## 发现与相关性

Glean 按已启用主题建立检索计划，但不对所有来源使用同一种过滤方式：

- Crossref 普通发现按第一组关键词逐个查询；PubMed、Europe PMC 使用布尔词组。
- 核心期刊补查按登记的 ISSN 获取全刊更新；arXiv、bioRxiv、medRxiv 按日期窗口获取，不执行主题关键词。
- 返回的有效记录先保存为候选。模型仅评估记录已关联的发现主题，人工决定最终纳入。

未被任何发现路径召回的论文不会进入后续判断；当前没有对来源全库执行跨所有主题的自动分类。细节见[来源访问与更新](reference/sources.md)。

## 数据与证据原则

- 论文身份、来源观察、主题成员关系和个人阅读状态分别保存；跨源按明确标识匹配，不按标题相似度合并。
- 发表日期、来源更新时间和采集时间分别记录；未知日期与证据保持未知。
- 取得摘要、取得全文、模型已处理、科学核验和人工纳入分别表达；机器结果不覆盖历史或人工结论。
- 坏记录隔离，其他有效记录继续处理；来源失败与合法空结果分别显示。
- 正常应用不回退模拟来源或模型。fixture/fake 只用于测试或显式演示模式。
