## 维护约定

- 当前行为写入对应使用说明或技术参考；待办只在 roadmap 维护，已完成变化写入 changelog。
- 命令注明适用环境。当前实例与仓库发布工具的目录不同，部署前先选择对应说明。
- 保留必要的迁移、恢复和验证限制；逐轮排查过程、完整测试输出和临时 CI 耗时表交由 Git 历史、测试报告和运行日志保存。
- 配置字段和接口以源码为准，行为变更同步更新文档。移动文件时同步检查相对链接和标题锚点。
