# Glean 领域论文追踪工作台的重构需求

## 研究者要解决的问题（X）

第一次跟踪一个领域，我想知道过去有哪些工作。下周再打开它，我想知道这周发表了什么、哪些旧论文刚被补进来、我关注的预印本有没有正式发表。找到几百篇以后，我需要按自己的研究问题反复筛选。清单里少了一篇我认识的论文，我还要能查出它漏在了哪里。

Glean 的首要任务，是让研究者在一处持续追踪一个领域的新作和历史论文。论文散落在不同的期刊、会议、预印本平台和索引中。工作台要汇集各处的发现，保留相互印证或有分歧的书目信息，让研究者看得出当前清单覆盖到了哪里。

## 现有做法与重构取舍（Y）

现版网页默认打开“精选目录”，新采到的论文通常先进入“待审核”。一篇本周发表的论文可能已经在库里，读者却会因为停留在精选目录而错过它。中文总结和模型排序能帮助选读已找到的文章。要解释一篇论文为什么缺席，则要分别查看目录筛选、检索方案和采集进度。[当前目录行为](reference/api.md#检索与集合) · [现有检索方案](guides/search-plans.md)

**首轮重构以领域的全部发现为默认入口。** 单源收录、缺摘要和等待审核的论文都应能找到。读者可以主动切到精选或恢复个人筛选，随时看清并撤销当前限制。重构沿用已有历史书目、论文链接、来源记录和人工纠错。[现有能力](features.md)

## 一个领域怎样追下去

以“大语言模型从文本构建知识图谱”为例。

1. **第一次建立追踪。** 用领域名称、关键词和回溯起点建立主题，例如把 `large language model` 和 `LLM` 作为同义表达。工作台要说明这个主题实际查哪些来源、查哪些字段，以及历史从哪一年开始。维护者可以补充旧称或重点会议，对受影响的年份重新检索。普通读者打开领域即可浏览。
2. **回来查看变化。** 在同一个领域里，能分别查看按发表或首次公开日期排列的新作、上次查看后首次发现的论文，以及已收录论文的版本或出版状态变化。一篇去年发表、今天才被索引的论文出现在本次补录中，发表年份仍是去年。历史回溯期间仍可追踪近期发表的工作。
3. **回头查一组旧工作。** 研究者可以从最新结果切到整个历史范围，组合条件，打开论文核对出处，再回到原来的筛选和列表位置。常用组合作为个人视图保存。下次打开时，同样的条件可以查到后来补进来的论文。临时缩小阅读范围只影响当前视图，领域追踪继续收集其他候选。

## 筛选怎样服务研究问题

| 研究者想找什么 | 应能使用的条件 |
| --- | --- |
| 记得的那篇文章 | 按题名、摘要关键词、作者检索，也可用 DOI、PMID 或 arXiv 标识精确查找。 |
| 某段时间、某类发表渠道的工作 | 选发表日期范围、期刊或会议、文献类型和预印本或正式发表状态。查看本次新增时可改用首次发现日期。 |
| 领域内的某条研究线 | 在主题内按任务、方法、研究对象或已有标签组合筛选。每个领域使用适合自己的维度，尚未标注的论文可单独查看。 |
| 需要亲自核对或继续阅读的论文 | 按收录来源、仅单源收录、书目信息待核或个人阅读状态筛选，并能回到领域的全部发现。 |

例如，研究者可以找“2023 至 2025 年，在 ACL **或** EMNLP 正式发表，且涉及实体关系抽取的论文”。同一筛选项内的多个值取并集，不同筛选项取交集。界面要显示已选条件和匹配的去重条目数，允许单独移除条件或排除某项。没选某个条件时，缺少该字段的论文仍在结果里。筛到零篇时，应能看出是哪些条件生效，并回退一步。

## 怎样核对来自不同出处的论文

发现候选时取所选来源的并集。新发现记录命中的来源和检索途径，导入的历史论文保留原书目出处，未知的发现途径标为未知。

现有六个来源中，Crossref 提供 DOI 登记题录和出版关系，PubMed 与 Europe PMC 可核对生物医学题录与 PMID，arXiv、bioRxiv 和 medRxiv 可核对预印本的公开日期和修订。Europe PMC 转收的 PubMed 记录应标出共同出处。对会议论文占主导的领域，可用官方会议目录核对漏项，再决定补接哪些来源。[来源与更新方式](reference/sources.md)

- **同一论文，多处收录。** DOI、PMID 等标识能确认同一出版条目时，列表只计一次，详情列出各来源的标识、原始链接和取得时间。若仅有相似题名，或标识分别指向不同作品，保留各条记录，供读者核对可能的关系。
- **同一研究，不同版本。** 同一预印本的修订归在其版本历史中。有明确出版关系时，预印本与正式发表条目相互链接，各自保留标识与日期。读者可以只筛正式版，也可以沿关系回看最早公开的版本。
- **同一字段，来源有分歧。** 先分清预印本公开、期刊在线发表和卷期出版的日期。若两个来源对同一版本的在线发表日期给出不同值，详情应并列两个原值和链接，让读者能回到出版方的文章页核对。采用某个值时说明依据，难以判定时标为待核，后续纠错保留原值。

## 怎样判断还漏了什么

按**领域、来源、检索条件和时间段**记录查找范围。领域列表旁显示各源查到了哪天。展开后能看到哪些时间段已查完且无命中，哪些因限流、分页中断或尚未回溯而待补。恢复后接着补齐缺页，对可能延迟索引的时段重叠补查，重复命中归入已有条目。

用独立于 Glean 检索结果的书目检验漏检。例如，从一届会议的官方目录和一篇领域综述的参考文献中，人工选出指定年份、符合该主题的论文，记下标识与入选理由。用这份书目核对“本轮检索找回的篇数 / 参照书目中的去重篇数”。逐篇检查漏项在所选来源中能否检到，区分来源尚未收录、检索词没覆盖、采集中断和归并错误。已经找到却被当前筛选隐藏的条目，单列为显示问题。这个比例只描述这份参照书目，调整方案后沿用同一份书目比较。

## 首轮重构的验收场景

| 给研究者的任务 | 可以核对的结果 |
| --- | --- |
| 同一周遇到一篇新作、一篇迟到的旧作和一篇已收预印本的修订 | 分别能从近期发表、本次新发现和已有论文更新中找到对应条目，并能指出每个日期的含义。 |
| 在主题里执行上面的 ACL / EMNLP 筛选，打开一篇再返回，保存后再次使用 | 两个会议的符合项都出现。移除年份后能找回更早的论文，返回列表时保留位置，新增匹配项进入保存的视图。 |
| 两个索引收录同一 DOI，另有一篇仅见于一个来源 | 列表共两个条目。可打开第一篇的两个出处核对字段，也能从单源筛选里找到第二篇。 |
| 用独立书目核对一次回溯，期间让一个来源在翻页时中断 | 能指出受影响的来源和时段。恢复后重算找回篇数，逐篇说明仍缺的原因，尚无依据的标为待查。 |

首轮以研究者能完成这些任务为交付条件。后续迭代依据实际漏项、误合并和筛选中遇到的障碍排序。[重构路线图](roadmap.md)
