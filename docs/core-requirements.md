# Glean 的核心需求

**Glean 要帮研究团队围绕一个长期问题积累文献，让每个人都能从已有工作和新发现中选出下一篇值得读的论文。**

项目从生物医学 AI、LLM / Agent 知识工程和生物医学世界模型三个主题的历史书目起步。课题还在继续，论文也陆续出现在不同的期刊和会议上。如果每次组会前都从头找，研究者既要重新辨认见过的论文，也要重新问同事当初为什么选了其中几篇。[历史书目说明](guides/baseline.md)

## 一份目录要回答的三个问题

1. **这个问题已经有哪些工作，后来又找到了什么？** 团队先说清想跟踪的研究问题，把不同出处的论文放到同一份目录里。第一次来的人能从已有书目入手，回来的人能认出上次整理以后的新发现。
2. **这篇论文值得我细读吗？** 阅读时间有限。读者需要先用中文了解作者研究了什么，再对照原题、摘要和出处，判断这篇论文与手头的问题有多大关系。
3. **哪些判断能留给下一次？** 维护者按主题决定是否纳入一篇候选论文，把理由留给整个团队。每位读者各自记下哪些读过、哪篇还在读，下次打开同一份书目时能继续自己的阅读。

## 用户故事

以一个跟踪“大模型怎样从文本中构建知识图谱”的课题组为例。

- **新成员接手课题。** 我在组里已有的书目里找到 AutoSchemaKG，想先看懂它要解决的问题，再去原文核对作者用了什么材料构建图谱，决定要不要从这篇读起。[AutoSchemaKG 论文与摘要](https://aclanthology.org/2026.acl-long.942/)
- **研究者准备下一次组会。** 上周我已经介绍过 AutoSchemaKG。这周我想看看围绕同一问题又找到了哪些工作，挑一篇和它对照着读，在组会上讲清两种方法各自能从文本里提取什么。
- **主题维护者挑选论文。** 有篇候选论文在题名里提到了知识图谱。我想从摘要和原文确认大模型在研究里做了什么。如果作者用它从文本中抽取实体和关系，我就能把这条具体的收录理由留给下一位整理书目的人。
- **读者继续上次的阅读。** 昨天我只读完了一篇论文的方法部分。今天我想找回这篇在读论文，接着看实验。刚入组的同事也能在同一目录里找到它，按自己的进度读。

## 调研与参考项目

Pontis 等人的两轮访谈与原型试用共有 61 位研究者参与。参与者会借助同行筛选文献，查找信息的方式也受课题阶段和对领域的熟悉程度影响。这给 Glean 的启发是把选文理由留在目录里，让后来者能判断前人的选择是否适合自己眼下的问题。[研究者如何跟进文献，UCL 作者存档](https://discovery.ucl.ac.uk/id/eprint/1502194/)

Amano 等人调查了 908 名环境科学研究者。根据受访者自报的用时，部分非英语母语群体读一篇英文论文比英语母语群体更费时。Glean 可以用中文题名和简介帮助读者选文，并保留原题和出处，供读者核对作者的表述。[关于科研语言成本的原始研究，PLOS Biology](https://journals.plos.org/plosbiology/article?id=10.1371/journal.pbio.3002184)

| 参考项目 | 已有做法 | 对 Glean 的启发 |
| --- | --- | --- |
| LitCovid | 从 PubMed 持续选取与 COVID-19 相关的论文，再按诊断、治疗等研究方向整理。 | 新发现补进已有主题目录，熟悉主题的人可以跟进新作，刚入门的人也能按同一问题查到旧作。[项目团队论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7778958/) |
| PubMed | 读者可以保存一次检索，通过邮件获知后来匹配的结果。 | 值得长期保留的是研究者反复要问的问题。下次查看时，新增结果应当容易辨认。[PubMed 检索提醒说明](https://pubmed.ncbi.nlm.nih.gov/help/#create-an-email-alert) |
| arxiv-sanity-lite | 读者标记感兴趣的论文后，可以找到与之相似的新作。 | 拿一篇已读论文作参照，读者更容易说明自己这周想找哪类新作来对照阅读。[项目说明](https://github.com/karpathy/arxiv-sanity-lite) |
| ASReview LAB | 审阅者根据题名和摘要判断相关性，可以留下备注，也可以打开论文链接细读。 | 发现一篇候选以后，维护者还要根据论文内容判断它是否属于这个主题，并能说明理由。[审阅说明](https://asreview.readthedocs.io/en/stable/lab/screening.html) |
| Zotero Groups | 成员可以共用课题组文献库，同时保有各自的个人库。 | 组里整理过的论文能直接交给新成员，每个人都可以在同一份书目上安排自己的阅读进度。[群组文献库说明](https://www.zotero.org/support/groups) |
