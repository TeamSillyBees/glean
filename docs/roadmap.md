# Glean 重构路线图

更新于 2026 年 11 月 25 日。首轮围绕一个研究者长期追踪的领域，优先改进发现论文、筛出所需结果和核对遗漏的过程。产品目标与当前实现分别见[重构需求](core-requirements.md)和[功能清单](features.md)。

## P0 交付可用的领域论文工作台

| 首轮工作 | 现有起点 | 完成标准 |
| --- | --- | --- |
| 以领域的全部发现为入口 | 已有自定义主题、历史书目和待审核候选，网页默认展示精选目录。 | 研究者打开领域就能找到历史论文与新候选，可按需切到精选。旧论文链接、主题归属、个人阅读记录和人工纠错可继续使用。 |
| 让追新与历史回溯并行 | 已有按来源分页、重叠补扫和中断恢复，也已记录发表、首次发现与来源更新等不同时间。 | 在一个领域运行历史回溯和连续两次增量，区分本期新作、迟到的旧作和版本更新。中断一个来源后能定位待补时间段并接着完成，其余来源的结果仍可浏览。 |
| 让筛选适用于新作和旧文 | 已有主题维度、年份、载体、来源和个人筛选偏好，年份和载体等条件当前取单值。 | 在同一主题内完成“年份范围 + 两个会议任选 + 任务”的查询，核对去重计数、缺失字段和取消条件后的结果。打开详情返回后保留位置，保存的条件能找到后来补入的匹配论文。 |
| 跨源核对书目 | 已有标识匹配、来源观察、人工纠错和部分预印本关系。 | 同一出版条目的跨源记录只计一次，单源论文可查。读者能比对有分歧的字段，打开各自出处，并辨认有明确关联的预印本和正式发表条目。 |
| 用已知论文查漏 | 检索方案可以记录质量检查，已有请求、发现路径和隔离记录。 | 用独立会议目录或综述建立一组相关论文，逐篇核对。用同一组论文比较调整前后的找回数，列出漏项、原因和仍待核实的项，据此挑选下一项改进。 |

## P1 根据实际缺口扩大覆盖

| 发现的问题 | 后续工作与完成标准 |
| --- | --- |
| 已知会议或领域的一批论文在现有来源查不到 | 用官方会议目录、DBLP、OpenAlex 或引文线索核对缺项。按能新增找到哪些论文、访问额度和许可选取补充来源，以同一书目复查。OpenAlex 的公开快照、检索和增量同步条件见[来源政策](reference/sources.md#openalex-待接入对照)。 |
| 老论文的后续变化落在原检索范围外 | 对已纳入、待核和预印本条目安排有界复核。补接 bioRxiv、medRxiv 的正式发表关系，以及 PubMed 删除、arXiv 删除标记、勘误和撤稿等事件，保留原记录和人工判断。 |
| 多个主题反复扫描同一份预印本日期列表 | 共享同一来源窗口的采集结果，同时保留各主题的命中路径、预算与恢复位置。根据跨主题漏项决定是否扩展分发规则。 |
| 现有词组难以表达查漏所需的检索式 | 根据实际漏项补充词表、字段或运算符。核对各来源实际执行的条件，用参照论文验证新增召回，并抽查新增候选的相关性。 |

## 持续运行与生产发布

- **启用持续采集。** 最近的实例记录中，线上自动采集处于关闭状态。启用前在选定范围验证分页入库、积压、失败退避和进程恢复，并补做六源持续运行及完整分页的实服验收。2026-11-07 的六源检查记录的是当次连通性。[实例记录](deployment/current-instance.md)
- **调度与限流。** 当前扫描间隔为 72 小时。评估每日增量时，按来源索引延迟、更新到达工作台的时间和积压调整频率，给历史回溯单列预算。服务器与 CLI 需按上游计量范围共享限流，处理 Crossref 响应头及各源认证参数。
- **部署与备份。** 当前实例使用单一 Compose，仓库发布工具使用 releases/state 布局。统一布局仍是首要部署工作。启用服务器发布前完成备份、迁移、镜像切换、失败恢复和回退演练。周期备份需明确保留期限、恢复点和恢复时间目标，并在独立主机核对数据库、角色、Redis、配置、文件、权限及采集连续性。[部署说明](deployment/README.md)

## 阅读辅助与其他后续工作

- 中文整理和模型优先分用于辅助选读。扩大模型处理前，用实际阅读材料与人工判断比较结果，区分元数据变更与材料变更，再评估结果复用、供应商用量对账和周期预算。
- 按来源许可明确原始响应、摘要和其他材料的保留、再分发与清理方式。当前保存的响应哈希用于比对内容。
- 账号体验另需在已安装并启用 1Password 的浏览器中复测扩展弹窗。
