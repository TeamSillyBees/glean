# Glean 的产品事实

本文件记录当前代码与用户需求共同确定的产品事实，不把本次视觉方案当作用户的长期审美偏好。

## 使用者与目标

面向持续检索、比较与阅读科研文献的研究者。中文优先，同时保留英文题名、来源原始信息和可追溯证据。核心任务是：选择研究主题，检索和筛选论文，打开详情核查内容，记录个人阅读状态；必要时查看采集健康与失败证据。

## 既有范围

- 三个内置主题：生物医学 AI、LLM / Agent 知识工程、生物医学世界模型；管理员可新增、编辑研究主题并暂停其后续检索。
- 原历史基线共 39,495 条主题成员关系，不等于 39,495 篇已科学核验论文。实际界面的计数由后端返回，禁止前端硬编码。
- 精选目录、待审核、已移出主题、全部记录分别查询；原始分类、纳入证据和个人阅读状态不可混为一谈。
- 搜索、主题精确筛选、来源筛选、排序、分页、详情证据、阅读/隐藏、偏好保存均已实现。
- 采集状态、扫描记录、只读恢复诊断与隔离记录来自真实后端；管理员可手动测试来源连通性，结果与采集进度分开显示。检索方案直接展示有效关键词和来源，管理员可就地编辑。期刊与会议使用服务端分页，默认按影响因子降序。

## 技术与安全边界

Go 独立后端，React / TypeScript / Tailwind / Radix 前端，TanStack Query 管理请求。认证令牌仅在页面内存；刷新后重新登录。主题分类与科学判断由后端提供，前端不自行改写。真实模型适配器已接入；未配置模型时显示待配置，不伪造摘要或科学审读结论。

管理入口包括用户管理、研究主题、检索方案编辑及详情中的论文管理。用户列表与新建/编辑复用一套表单；主题和检索方案复用相同的写入与版本校验；审核、标注和纠错就地完成，不增加审批流。普通用户只维护自己的阅读、隐藏和筛选偏好；管理员的主题内审核与全局书目纠错对所有用户可见，保留原始来源与修改历史。

元数据纠错仅支持原文标题、中文标题、作者、年份、期刊/会议、摘要；DOI、arXiv 标识、日期和 URL 不在编辑范围。移出主题不是删除；取消字段纠错后保存即可恢复来源值。账号管理不增加自行注册或密码重置入口。新增主题不自动开始采集或开启全局调度；旧运行恢复继续使用其冻结的模板。操作说明见[管理指南](../docs/glean/management.md)。

默认测试不依赖公开来源的实时可用性；实时来源验收由独立手动工作流执行。

## 使用环境

长时间桌面阅读为主要场景，同时保留手机的导航、筛选和详情操作。网络请求可能延迟或失败；加载、错误、空状态和过期数据必须可区分。键盘操作与焦点返回是功能要求，不因外观重构而削弱。
