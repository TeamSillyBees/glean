# Glean 的产品事实

本文件记录当前代码与用户需求共同确定的产品事实，不把本次视觉方案当作用户的长期审美偏好。

## 使用者与目标

面向持续检索、比较与阅读科研文献的研究者。中文优先，同时保留英文题名、来源原始信息和可追溯证据。核心任务是：选择研究主题，检索和筛选论文，打开详情核查内容，记录个人阅读状态；必要时查看采集健康与失败证据。

## 既有范围

- 三个独立主题：生物医学 AI、LLM / Agent 知识工程、生物医学世界模型。
- 原历史基线共 39,495 条主题成员关系，不等于 39,495 篇已科学核验论文。实际界面的计数由后端返回，禁止前端硬编码。
- 精选目录、新发现待审、全部记录分别查询；原始分类、纳入证据和个人阅读状态不可混为一谈。
- 搜索、主题精确筛选、来源筛选、排序、分页、详情证据、阅读/隐藏、偏好保存均已实现。
- 来源健康、扫描记录、只读恢复诊断、检索模板、期刊与会议登记、隔离记录均为真实后端查询界面。

## 技术与安全边界

Go 独立后端，React / TypeScript / Tailwind / Radix 前端，TanStack Query 管理请求。认证令牌仅在页面内存；刷新后重新登录。主题分类与科学判断由后端提供，前端不自行改写。只有 LLM 阅读/总结仍为明确标识的 mock，真实采集、数据库、历史数据与个人状态不是模拟运行。

本次 UI 重构不增加后端写入口，不更改账户、数据模型、科学结论、搜索语义、分页规则或采集权限。默认测试不依赖公开来源的实时可用性；实时来源验收由独立手动工作流执行。

## 使用环境

长时间桌面阅读为主要场景，同时保留手机的导航、筛选和详情操作。网络请求可能延迟或失败；加载、错误、空状态和过期数据必须可区分。键盘操作与焦点返回是功能要求，不因外观重构而削弱。
