# Glean Web 界面设计

## 方法与范围

本次为视觉与布局重构，不是换主题色。选择 **Impeccable** 的 Operate / Read 方法：工作台用于检索与操作，详情用于阅读与证据核验。Hallmark 仅用于方案比较，未叠加其主题或安装脚本。

参考版本：[pbakaus/impeccable](https://github.com/pbakaus/impeccable/tree/d34c87e1a00989ae8dbdd7f6b30b70f23319e860)，skill 4.8.0，Apache-2.0。实际阅读了 SKILL.md，以及 mode-operate、mode-read、layout、craft-floor 等设计指导；使用现有 React / Radix 实现其方法，不执行其安装器、下载二进制或启用 hook，也不声称跑过该项目的 CLI 检测。

产品事实见 [PRODUCT.md](PRODUCT.md)。下列视觉方向是此次实现选择，不是从用户话语推断出的永久偏好。

## 视觉方向：清晰、连续的研究工作台

- 深森林色导航承载位置与任务分组，白色阅读区承载论文，暖纸色背景区分工作区域。
- 优先展示当前任务、搜索范围、真实结果和论文题名。移除英文眉题、装饰光圈、渐变主题横幅和重复的宣传卡片。
- 主题规则与统计合为紧凑资料行，不把数据库总量设计成营销式大数字。
- 论文采用连续文献列表：一层外框、条目间细分隔、题名强于元信息；不在每一行再堆阴影和圆角卡片。
- 证据与个人状态通过标签、文本和分隔区分，不能只靠颜色识别。来源警告仍使用 amber/red 等语义状态色。
- 品牌识别来自导航材质、开卷标记与文献式行列节奏，不用伪造图表、插画、照片或研究数据装饰。

## 文字与节奏

- 原生中文字体栈：PingFang SC、Microsoft YaHei、Noto Sans CJK SC、system-ui。没有外部字体请求；工作台采用熟悉的系统文字，而非增加与阅读无关的展示字体。
- 工作台标题桌面 27px、手机 23px；论文题名 17–18px；操作正文 13–14px；阅读正文 15–16px；支持性信息通常不低于 12px。
- 4px 基础节奏，相关元素间 4–12px，区域间 18–28px。文字行高按阅读密度而非平均填满空间设置。
- 数量与分页采用 tabular numerals；长标题可换行，ID 和参数允许断行，筛选值不改变原标签内容。

## 布局与适配

- ≥1024px：224px 固定导航。≥1280px：216px 筛选列与弹性文献列；≥1600px 筛选列 232px。
- 较窄屏幕保留标准导航/筛选抽屉，目录范围、排序和阅读状态自然换行；不靠缩小整页强行容纳。
- 主搜索始终在内容区上方。主题介绍缩为内联资料行；手机优先保留真实统计，不展示宽幅装饰。
- 手机触摸模式的主要按钮、导航、目录范围和 combobox 最小高度 44px；辅助说明、清空搜索与浮层关闭也保留 44px 触摸目标。
- 详情保持 Radix 模态焦点与关闭后的焦点恢复；不覆盖请求、保存和会话隔离逻辑。

## 状态、动效与验证

悬停与选中使用明确色差，键盘焦点 2px，错误/空状态保留可执行的恢复操作。没有入场动画或滚动叙事；必要的短颜色过渡不阻塞任务。`prefers-reduced-motion` 禁用非必要过渡与平滑滚动。输入光标、选中文字和滚动条跟随同一色系。

验证须分别记录：组件测试、类型/lint/build、真实数据库与桌面/手机 E2E，以及实际截图人工检查。静态样式检查不等于浏览器视觉通过，DOM 测试不等于真实失败数据已完成端到端验收。截图来源与最终 CI 由交付文档记录，不在此文档预先声称通过。
